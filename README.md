# ECommerceCsvImport

Модуль импорта товаров (Вариант 2: Книги) из CSV-файлов для электронного магазина.

## Технологии
- C# / ASP.NET Core MVC (.NET 8)
- xUnit (модульное тестирование)
- Git

## Запуск
1. Открыть решение `ECommerceCsvImport.sln` в Visual Studio.
2. Запустить проект (F5).
3. На странице импорта указать путь: `/csv/sample_products.csv`
